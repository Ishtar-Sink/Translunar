# Catálogo de Habilidades

## Padrão

Habilidades incluídas junto ao harness.

| Habilidade | Descrição | Caminho |
|    ---     |    ---    |   ---   |
| refine-spec | Refina uma especificação (spec) em rascunho. Investiga o projeto e a memória, identifica ambiguidades, conflitos e lacunas, resolve com o usuário em rodadas de perguntas e gera em `refined/` uma spec detalhada, com seções conforme o tipo (feature, improvement, fix, study, analysis). Use quando o usuário pedir para refinar, detalhar ou esclarecer uma spec em rascunho (status draft), ou perguntar quais specs em draft estão prontas para refinamento. Não use para specs já refinadas: ajustes nelas são feitos pela skill adjust-spec. | `../skills/default/refine-spec` |
| create-skill | Cria uma nova skill do harness no formato padrão: gera o SKILL.md a partir do template, os redirecionamentos para Claude Code, Codex e Cursor e a entrada no catálogo, e propõe subcomandos do vostok para as operações determinísticas. Use quando o usuário pedir para criar, adicionar ou gerar uma skill ou habilidade, ou transformar um fluxo de trabalho em skill. Use sempre esta skill em vez dos criadores de skill nativos das ferramentas. | `../skills/default/create-skill` |
| adjust-spec | Ajusta uma especificação (spec) já refinada, com status refined ou approved. Aplica um ou vários ajustes pedidos numa mesma mensagem, em prosa, em lista ou citando o trecho exato, registra edições feitas à mão e mantém o histórico de ajustes da spec, validando-a com as mesmas regras do refinamento. Use quando o usuário pedir para ajustar, corrigir, mudar, alterar, acrescentar ou remover algo de uma spec refinada ou aprovada, ou comentar a spec logo depois de ela ser refinada ou ajustada. | `../skills/default/adjust-spec` |
| approve-spec | Aprova uma especificação (spec) refinada, com status refined. Confere se a spec está válida, sem pendências abertas e sem edições manuais sem registro, muda o status para approved, grava a versão aprovada para a granularização e remove o rascunho. Use quando o usuário pedir para aprovar uma spec, disser que aprova ou que a spec está aprovada, ou citar um ID como SPEC-001 para aprovação. | `../skills/default/approve-spec` |
| plan-tasks | Planeja as tarefas de uma especificação (spec) aprovada, com status approved. Cria um plano para revisão em work/plans/, com a visão geral, a tabela de tarefas, as dependências, os IDs cobertos e o nível de esforço sugerido de cada tarefa, calculado pelo vostok. Use quando o usuário pedir para planejar, propor, granularizar ou quebrar em tarefas uma spec aprovada. Não use para ajustar um plano existente (skill adjust-plan) nem para aprová-lo (skill approve-plan). | `../skills/default/plan-tasks` |
| adjust-plan | Ajusta o plano de tarefas de uma especificação (spec) aprovada, em work/plans/. Aplica um ou vários ajustes pedidos numa mesma mensagem (dividir, juntar, remover ou reordenar tarefas, mudar dependências, cobertura ou fatos de esforço), registra edições feitas à mão, recalcula os níveis e mantém o histórico de ajustes do plano. Use quando o usuário pedir para ajustar, corrigir, mudar, dividir, juntar ou remover algo do plano de tarefas, ou comentar o plano logo depois de ele ser criado ou ajustado. | `../skills/default/adjust-plan` |
| approve-plan | Aprova o plano de tarefas de uma especificação (spec) aprovada. Cria um arquivo por tarefa na pasta de tarefas da spec, em work/tasks/, detalha cada uma com a execução para o agente (arquivos, passos, verificação) e a descrição para pessoas (resumo executivo, detalhes técnicos e card para board), remove o plano e marca a spec como planned. Use quando o usuário pedir para aprovar o plano de tarefas ou disser que aprova o plano. | `../skills/default/approve-plan` |
| approve-commit | Faz commits a pedido do usuário, já liberados, e libera ou desfaz os commits apontados pela verificação de commits (vostok commit check): commits feitos sem liberação, pelo agente ou pelo próprio usuário. Liberar grava o estado atual do repositório como referência; desfazer remove os commits novos da branch atual mantendo as alterações na pasta de trabalho. Use quando o usuário pedir para fazer commit, ou para liberar, aprovar, aceitar, desfazer ou reverter os commits apontados. | `../skills/default/approve-commit` |
| approve-task | Aprova tarefas de uma especificação (spec) planejada, em work/tasks/: uma, várias ou todas as pendentes. Confere se cada tarefa está pendente, sem edição manual sem registro e válida, e grava a aprovação em todas ou em nenhuma. Use quando o usuário pedir para aprovar tarefas, citar IDs como TASK-01 para aprovação ou disser que aprova as tarefas. | `../skills/default/approve-task` |
| adjust-task | Ajusta uma tarefa de uma especificação (spec) planejada, em work/tasks/, em qualquer status menos done. Aplica um ou vários ajustes pedidos numa mesma mensagem (arquivos a ler ou mudar, passos, baseline, verificação, evidências, critérios de conclusão ou descrição), registra edições feitas à mão e mantém o histórico de ajustes da tarefa. Uma tarefa aprovada volta para aprovação; uma em execução volta para in_progress, sem nova aprovação. Use quando o usuário pedir para ajustar, corrigir, mudar ou detalhar algo de uma tarefa, ou comentar uma tarefa antes de executá-la. | `../skills/default/adjust-task` |
| execute-task | Executa uma tarefa aprovada de uma especificação (spec), em work/tasks/: confere se ela pode começar, coleta o baseline antes de qualquer mudança, implementa os testes pedidos em Verificação e depois o código, seguindo os passos, sem commit nem stage, e termina com a tarefa em execução, pronta para ser finalizada. Uma tarefa por pedido. Use quando o usuário pedir para executar, implementar, fazer ou começar uma tarefa, ou citar um ID como TASK-03 para execução. | `../skills/default/execute-task` |
| finish-task | Finaliza uma tarefa em execução, em work/tasks/, só a pedido do usuário: executa os testes da Verificação, compara com o baseline para achar regressões, grava as evidências, confere os critérios de conclusão e marca a tarefa como done, e a spec como implemented na última tarefa. Bloqueia a tarefa depois do máximo de falhas ou numa regressão e a retoma com a decisão do usuário. Use quando o usuário pedir para finalizar, concluir, validar, testar ou revalidar uma tarefa em andamento, ou para retomar uma tarefa bloqueada. | `../skills/default/finish-task` |
| finalize-spec | Finaliza uma especificação (spec) implementada, com status implemented e todas as tarefas done, só a pedido do usuário: lê as fontes (spec, tarefas, evidências, memória, commits e código), sintetiza o conteúdo dos documentos executivo, técnico e de evidências, gera os três HTML, arquiva a spec com as tarefas e publica o executivo e o técnico em docs/specs/. Use quando o usuário pedir para finalizar, fechar, encerrar ou arquivar uma spec implementada, ou gerar os documentos finais de uma spec. | `../skills/default/finalize-spec` |
| init-harness | Inicializa o harness num projeto: investiga o código (manifestos, configurações de lint e de teste, estrutura de pastas), propõe regras por categoria citando a origem de cada uma, pergunta numa única rodada o que não se aplica, quais regras valem e onde cada categoria é carregada, e grava só o confirmado em rules/project/ e no mapa de contexto. Numa reexecução, mostra o que mudaria e altera só o que o usuário confirmar. Use quando o usuário pedir para inicializar o harness, levantar as regras do projeto, configurar as regras ou rodar o init. | `../skills/default/init-harness` |
| adjust-rules | Ajusta as regras do projeto, em rules/project/, e o mapa de carregamento do contexto, em config/context.yml. Aplica um ou vários ajustes pedidos numa mesma mensagem: criar, alterar ou remover uma regra, criar uma categoria de regras e incluir, mover ou retirar uma regra do mapa de uma skill ou do contexto obrigatório. Também grava a regra sugerida pelo agente depois que o usuário a aprova. Use quando o usuário pedir para criar, mudar, remover ou carregar uma regra ou categoria de regras do projeto, ou aprovar uma sugestão de regra. | `../skills/default/adjust-rules` |
| report-harness-bug | Relata um defeito do próprio harness Vostok (CLI vostok, skills, regras, templates e configuração distribuídos), nunca do projeto do usuário: monta o relato a partir do template em work/bugs/, troca dados do projeto por exemplos neutros, mascara segredos, valida com vostok bug check, mostra o relato inteiro e, só com a autorização do usuário, cria a issue no repositório do harness com gh ou entrega o link preenchido para abrir no navegador. Use quando o usuário pedir para reportar, relatar ou abrir uma issue de um bug do harness ou do vostok, como 'reporta esse bug do harness' ou /report-harness-bug. Não use para defeitos do código, das regras ou das skills customizadas do projeto do usuário. | `../skills/default/report-harness-bug` |
| validate-harness-bug | Valida a correção de um defeito do próprio harness Vostok (CLI vostok, skills, regras, templates e configuração distribuídos), não do projeto do usuário: encontra as issues [harness-bug] do usuário respondidas com a correção, reinstala a versão citada, roda vostok update, segue os passos de retomada da resposta, confere se o defeito relatado deixou de acontecer e, com autorização, comenta o resultado e fecha a issue. Use quando o usuário pedir /validate-harness-bug, "valida a correção do bug do harness", ou disser que a issue #N foi respondida. Não use para defeitos do projeto do usuário. | `../skills/default/validate-harness-bug` |

## Customizadas

Habilidades criadas pelo usuário. Toda inclusão e remoção de habiliades deve ser atualizado nesta tabela.

| Habilidade | Descrição | Caminho |
|    ---     |    ---    |   ---   |
| translate-subtitles | Traduz e localiza a legenda pt-BR de um corte do Translunar para os idiomas escolhidos: recebe o caminho do pt.srt no server, pergunta os idiomas, lê perfis, glossário e contexto, grava um {idioma}.srt sincronizado ao lado do pt.srt e só termina com a validação do legendar aprovada. Use quando o usuário colar um caminho de pt.srt do Translunar ou pedir para traduzir/legendar um corte. | `../skills/custom/translate-subtitles` |
