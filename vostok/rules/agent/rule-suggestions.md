# Sugestão de regras

Define quando e como o agente sugere incluir ou alterar uma regra do projeto.

[agent/rule-suggestions-01]: Ao notar o mesmo padrão ao menos 3 vezes (correção repetida do usuário, convenção repetida no código), sugira a inclusão ou a alteração de uma regra de projeto.
[agent/rule-suggestions-02]: Faça a sugestão com o template `question`, citando as ocorrências que formam o padrão.
[agent/rule-suggestions-03]: Faça no máximo uma sugestão de regra por resposta.
[agent/rule-suggestions-04]: Nunca grave, altere ou remova uma regra sem a autorização do usuário.
[agent/rule-suggestions-05]: Com a sugestão aprovada, aplique-a pela skill `adjust-rules`.
